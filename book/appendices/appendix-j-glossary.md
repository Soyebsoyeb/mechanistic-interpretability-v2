# Appendix J — Glossary

- **Activation**: Output value of a neuron or component
- **Ablation**: Removing or zeroing a component
- **Activation patching**: Replacing activation from clean run into corrupted run
- **Attribution**: Assigning importance scores to components
- **Circuit**: Computational subgraph responsible for a behavior
- **Feature**: Functional pattern represented in the model
- **Mechanistic interpretability**: Reverse engineering neural network computations
- **Polysemanticity**: Single neuron representing multiple concepts
- **Residual stream**: Central communication channel in transformers
- **Sparse autoencoder**: Autoencoder with sparsity constraint
- **Superposition**: Representing more features than dimensions
- **Causal intervention**: Modifying a component to test causal effect
- **QK circuit**: Query-Key circuit controlling attention patterns
- **OV circuit**: Output-Value circuit controlling information copying
- **Logit lens**: Projecting residual states onto vocabulary space
- **Induction head**: Attention head that copies previous tokens
- **Faithfulness**: How well a circuit explanation matches the model
- **Falsifiability**: Whether a hypothesis can be proven wrong
