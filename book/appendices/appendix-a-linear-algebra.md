# Appendix A — Linear Algebra

- Matrix multiplication: $AB \in \mathbb{R}^{m \times k}$ for $A \in \mathbb{R}^{m \times n}, B \in \mathbb{R}^{n \times k}$
- Eigenvectors: $Av = \lambda v$
- Orthogonality: $x^\top y = 0$
- Projection: $P = UU^\top$ for orthonormal $U$
- SVD: $W = U\Sigma V^\top$
- Trace: $\text{tr}(AB) = \text{tr}(BA)$
- Frobenius norm: $\|A\|_F = \sqrt{\sum_{i,j} A_{ij}^2}$
