# Appendix J — Glossary

- **Activation**: Output value of a neuron or component after forward pass
- **Ablation**: Removing or zeroing a component to test necessity
- **Activation Patching**: Replacing activation from clean run into corrupted run
- **Attribution**: Method for assigning importance scores to components
- **Circuit**: Computational subgraph responsible for a specific behavior
- **Feature**: Functional pattern represented in the model (not necessarily a single neuron)
- **Mechanistic Interpretability**: Reverse engineering neural network computations
- **Polysemanticity**: Single neuron representing multiple unrelated concepts
- **Residual Stream**: Central communication channel in transformers, sum of all layer outputs
- **Sparse Autoencoder**: Autoencoder with sparsity constraint on hidden layer
- **Superposition**: Representing more features than available dimensions
- **Causal Intervention**: Modifying a component to test causal effect
- **QK Circuit**: Query-Key circuit controlling attention patterns
- **OV Circuit**: Output-Value circuit controlling information copying
- **Logit Lens**: Projecting intermediate states onto vocabulary space
- **Induction Head**: Attention head that copies information from earlier in sequence
- **Faithfulness**: Degree to which a circuit explanation matches the full model
- **Falsification**: Actively seeking evidence that disproves a hypothesis
