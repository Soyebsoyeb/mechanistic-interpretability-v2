## Book Manifesto

This book treats mechanistic interpretability as a rigorous scientific discipline whose sole objective is to reverse engineer the computations implemented by trained neural networks.

### The Central Workflow

```
Behavior → Observation → Hypothesis → Mathematical Model → Code → Intervention → Evidence → Mechanistic Explanation
```

### The Eight Questions

For every important claim in this book, the reader must be able to answer:

1. **What exactly is being claimed?**
2. **What mathematical object represents the claim?**
3. **Where does it exist in the model?**
4. **How can it be measured?**
5. **How can it be intervened upon?**
6. **What result would falsify the hypothesis?**
7. **Can the result be reproduced?**
8. **What alternative explanations remain?**

### Disciplines Integrated

Linear algebra, probability theory, information theory, optimization, neural-network mathematics, transformer architecture, representation learning, sparse coding, causal inference, experimental design, PyTorch engineering, interpretability tooling, synthetic-model experiments, language-model experiments, circuit analysis, feature discovery, reasoning-model analysis, and AI safety.

### The Ultimate Standard

> **Mathematical clarity + Executable implementation + Causal evidence + Reproducibility**

## How to Read This Book

Each major concept follows this architecture:

| Step | Question |
|------|----------|
| 1. Concept | What phenomenon are we trying to understand? |
| 2. Formalization | What mathematical object represents it? |
| 3. Derivation | Where does the equation come from? |
| 4. Implementation | How is the equation implemented in code? |
| 5. Measurement | How do we quantify the phenomenon? |
| 6. Intervention | What happens if we modify the suspected mechanism? |
| 7. Falsification | What observation would invalidate the hypothesis? |

## Coding Standard

All code in this book:
- Uses explicit shapes in docstrings
- Documents every tensor dimension
- Avoids unexplained magic constants
- Separates model logic from experiment logic
- Uses deterministic seeds where possible
- Includes unit tests
- Saves experiment metadata
- Generates figures programmatically
- Reports failures clearly

---

## Publication Principle

This book **never** presents an interpretation as established merely because:
- A neuron has an intuitive label
- An activation correlates with a concept
- An attention pattern looks meaningful
- An attribution method ranks a component highly
- An automatically generated explanation sounds convincing

Instead, we distinguish:

```
Observation
Hypothesis
Evidence
Causal validation
Remaining uncertainty
```
